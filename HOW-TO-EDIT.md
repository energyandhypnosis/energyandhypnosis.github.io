# How to edit your website (no coding needed)

Everything is edited on github.com. After you **Commit changes**, the site updates in about 1–2 minutes.

## Write a new blog article
1. Open the `_posts` folder → **Add file → Create new file**.
2. Name it `YEAR-MONTH-DAY-short-title.md`, e.g. `2026-09-15-why-anxiety-is-a-state.md`.
3. Copy everything from `_posts/_TEMPLATE-copy-me.md` into it, then write your article.
4. Set `category:` to `Article` or `Research`.
5. Click **Commit changes**.

## Add a picture
Open `assets/img` → **Add file → Upload files** → drag your picture in → **Commit changes**.
Use it in an article with: `![Describe the picture](/assets/img/your-picture.jpg)`

## Change a setting
Open `_data/settings.yml`, click the ✏️ pencil, change the text between the quotes, **Commit changes**.

## Edit testimonials
Open `_data/testimonials.yml` and edit or add an entry (keep the same indentation).

## Replace the free PDF or audio
Open `assets/downloads` → **Add file → Upload files** → upload a file with the **exact same name** → **Commit changes**.

# melissabrownenergy.com

Website for **Melissa Brown Energy — Tranceform Hypnotherapy**, hosted free on GitHub Pages.

- **Edit settings** (email forms, workshop day/time, Zoom link, social links): `_data/settings.yml`
- **Write a blog post**: see [HOW-TO-EDIT.md](HOW-TO-EDIT.md)
- **Free downloads**: upload files into `assets/downloads/`

## Launch checklist
1. **MailerLite**: create an account, a `Newsletter` group, one group + embedded form per freebie (protocol, audio, workshop, app waitlist, newsletter). Each form must add people to **Newsletter** too. Paste the account ID and form IDs into `_data/settings.yml`.
2. **MailerLite automations**: one welcome automation per group that emails the freebie (PDF link / audio link / Zoom link + weekly reminder).
3. **Upload** `rewire-your-brain-30-day-protocol.pdf` and `free-hypnosis-audio.mp3` to `assets/downloads/`.
4. **Workshop**: fill in `day`, `time_24h` and `zoom_link` in settings.
5. **Consult reminders**: Calendly → Workflows (Standard plan) → "Email reminder to invitees" 24h and 1h before.
6. **Export contacts from Kajabi** (People → Export) and import them into MailerLite (only people who agreed to receive emails).
7. **Connect the domain** (Settings → Pages → Custom domain) and update DNS at the registrar.
8. Review the privacy policy page.
